### VScode Extension
1. Write an [extension](https://github.com/zcyisiee/vscode-picgo-paste) for VSCode, which can upload the picture while pasting it to markdown. Use a simple approach by integrating [PicGo-Core](https://github.com/PicGo/PicGo-Core). After configuring picgo, user just need to press 'cmd + v' to trige the automatic upload process. I learn the [project structure](https://www.cnblogs.com/liuxianan/p/vscode-plugin-hello-world.html) of VSCode Extension development at the sametime. 
2. By the way, Claude-Opus-4.5 is really powerful. With a simple prompt: `develop an extention for vscode, which function is upload picture while paseting it in a markdown files. u just need calling 'picgo' tool in command line.`, and revised for twice, it run successfully. 
3. Publish the extension to [VScode marketplace](https://marketplace.visualstudio.com/items?itemName=zcyisiee.vscode-picgo-paste#review-details), and sent a PR to [Awesome-PicGo](https://github.com/PicGo/Awesome-PicGo/pull/141).
