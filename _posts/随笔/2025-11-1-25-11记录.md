## 2025-11-30

### llm-course 
[llm-course](https://huggingface.co/learn/llm-course) , provided by HuggingFace, is incredibly beginner-friendly — one of the most accessible, comprehensive, and sufficiently in-depth courses for anyone who wants solid knowledge of LLMs and practical techniques for working with [Transformers](https://huggingface.co/docs/transformers/index).

A practical study path could be: (1) **Textbook**: [Deep Learning from Scratch](https://www.ituring.com.cn/book/1921) — for basic DL foundations -> (2) **Online course**: [happy-llm](https://datawhalechina.github.io/happy-llm) — covers the basics and gives a comprehensive overview of LLMs; simpler than HuggingFace’s llm-course -> (3) **Online course**: [llm-course](https://huggingface.co/learn/llm-course) — deeper, very readable, and builds everything from scratch. Truly a “best-of-everything” course that’s a pleasure to read. Dives into many concepts that are skipped in [happy-llm](https://datawhalechina.github.io/happy-llm).

[llm-course](https://huggingface.co/learn/llm-course) also gives many links to deeper resources and documentations, for example, [Advanced cookbook](https://huggingface.co/learn/cookbook), [Dataset performence](https://huggingface.co/docs/datasets/about_arrow), [Transformers performence](https://huggingface.co/docs/transformers/main/en/performance). 
### llm-course Chapter 2: Using Transformers

1. **Head**: The base model output a hidden state, which need 'Head' module transform it to final output. ![image](https://raw.githubusercontent.com/zcyisiee/blog-images/main/科研/vscode_picgo_1764510972096.png)
2. **Multiple sequences**: 
    ```python
    tokens = tokenizer(
        sequences, 
        padding=True, 
        truncation=True, 
        return_tensors="pt" # return tensor type as pytorch.
        )
    ```
3. **Optimizing inference deplyment**: FlashAttention in TGI, PagedAttention in vLLM, and lamma.cpp. 
4. **Tokenizer**: 
     ```python
     tokenizer = AutoTokenizer.from_pretrain(checkpoint)
     model_inputs = tokenizer(sequences) 
     # Here, tokenizer is called as a class, it use '__call__' magic method in python. 
     # It's similar to writing:
     AutoTokenizer(checkpoint)(sequences)
     ```
